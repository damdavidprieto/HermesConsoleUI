# Política de Seguridad

## Versiones Soportadas

Publicamos parches para vulnerabilidades de seguridad. Las versiones elegibles para recibir dichos parches dependen de la Calificación CVSS v3.0:

| Versión | Soportada          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reportar una Vulnerabilidad

Por favor, reporte vulnerabilidades de seguridad abriendo un Aviso de Seguridad de GitHub en:
https://github.com/YOUR_USERNAME/PSConsoleUI/security/advisories/new

**Por favor, no reporte vulnerabilidades de seguridad a través de issues públicos de GitHub.**

### Qué Incluir

Al reportar una vulnerabilidad, por favor incluya:

* Tipo de problema (ej. desbordamiento de búfer, inyección SQL, cross-site scripting, etc.)
* Rutas completas de los archivos fuente relacionados con la manifestación del problema
* La ubicación del código fuente afectado (tag/branch/commit o URL directa)
* Cualquier configuración especial requerida para reproducir el problema
* Instrucciones paso a paso para reproducir el problema
* Código de prueba de concepto o exploit (si es posible)
* Impacto del problema, incluyendo cómo un atacante podría explotarlo

### Línea de Tiempo de Respuesta

* Confirmaremos la recepción de su reporte de vulnerabilidad dentro de 48 horas
* Proporcionaremos una respuesta más detallada dentro de 7 días
* Trabajaremos con usted para entender y resolver el problema
* Divulgaremos públicamente la vulnerabilidad después de que se publique una corrección

## Política de Actualización de Seguridad

* Las actualizaciones de seguridad se publicarán tan pronto como sea posible después de que se confirme una vulnerabilidad
* Los usuarios serán notificados a través de releases de GitHub y avisos de seguridad
* Las vulnerabilidades críticas serán priorizadas y publicadas inmediatamente

## Mejores Prácticas

Al usar PSConsoleUI:

* Siempre use la última versión
* Revise el CHANGELOG para actualizaciones relacionadas con seguridad
* No ejecute scripts de PowerShell no confiables
* Valide todas las entradas de usuario en sus aplicaciones
* Siga las mejores prácticas de seguridad de PowerShell

## Contacto

Para cualquier pregunta relacionada con seguridad, por favor abra un issue de GitHub o contacte a los mantenedores.
